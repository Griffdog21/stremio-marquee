Install

Publish free with GitHub

Saves your design as presets/<address>.json in your Marquee repository. GitHub builds and hosts it like the stock themes, refreshed daily. It's live about two minutes after you commit.

Using someone else's Marquee site?

Fork the repository. In your fork, open Actions and enable workflows, then set Settings → Pages → Source to GitHub Actions. Enter your fork above, e.g. you/stremio-marquee.

Prefer a live server? Changes apply instantly

A Marquee server renders your setup on demand, straight from its install link, with no commit needed.
