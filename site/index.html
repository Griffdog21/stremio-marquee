Add-ons live in your Stremio account, so install from any device and they appear everywhere you're signed in.

What changes where

Stremio add-ons can send rows, posters, images and text to every Stremio app, but they can't recolor the app's own menus. Marquee themes everything an add-on can reach, and ships full UI themes for the apps that accept CSS.

Lineup · beta

Put your theme front and center

Stremio orders home rows by add-on. Lineup reorders them and hides rows you don't want, straight from your browser, so Marquee leads your TV's home screen.

Open Lineup
Is my password safe?

Lineup runs entirely in your browser and talks only to Stremio's own API (api.strem.io). Nothing is stored or sent anywhere else. You can also paste an auth key instead of a password.

Can I undo it?

Every save downloads a backup of your add-on list first, and Lineup can restore it in one click.

FAQ

Questions

Why can't an add-on recolor the Stremio app itself?

Stremio add-ons speak a data protocol: they return catalogs, metadata, streams and subtitles. They can't inject styles into the app. So on TVs and phones Marquee themes what add-ons control (the posters, rows and images on your home screen), and on desktop and web it adds full CSS themes.

Does Marquee stream anything?

No. Marquee only provides themed catalog rows. Titles keep their real IMDb IDs, so your existing stream add-ons, watch history and library all work exactly as before.

Do I need to run a server?

Not for the eight ready-made themes. They're static files on GitHub Pages, rebuilt daily so trending rows stay fresh. Fully custom setups from the Studio need a free server, which you can deploy in one click.

Where does the data come from?

From Cinemeta, the same open catalog Stremio uses for its own home screen. The art is generated from each title's name, year, genres and rating, so no studio artwork is copied.

Will it slow down my TV?

Posters are small, cached JPEGs (about 30 KB each), comparable to Stremio's own.
