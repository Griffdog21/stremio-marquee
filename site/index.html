Install Midnight Neon

Add-ons live in your Stremio account, so install from any device and they appear everywhere you're signed in.

  1. On your phone or computer, tap Install in Stremio. No app on this device? Use Stremio Web instead.
  2. Sign in to the same Stremio account on your Google TV. The add-on syncs over automatically; restart Stremio on the TV if it was already open.
  3. Make it your home screen: new add-ons land below Stremio's own rows. Lineup moves Marquee to the top and hides the duplicate Cinemeta rows in one click.

Lineup · beta

Put your theme front and center

Stremio orders home rows by add-on. Lineup reorders them and hides rows you don't want, straight from your browser, so Marquee leads your TV's home screen.

Open Lineup
Is my password safe?

Lineup runs entirely in your browser and talks only to Stremio's own API (api.strem.io). Nothing is stored or sent anywhere else. You can also paste an auth key instead of a password.

Can I undo it?

Every save downloads a backup of your add-on list first, and Lineup can restore it in one click.

FAQ

Questions

Why can't an add-on recolor the Stremio app itself?

Stremio add-ons speak a data protocol: they return catalogs, metadata, streams and subtitles. They can't inject styles into the app. So on TVs and phones Marquee themes what add-ons control (the posters, rows and images on your home screen), and on desktop and web it adds full CSS themes.

Does Marquee stream anything?

No. Marquee only provides themed catalog rows. Titles keep their real IMDb IDs, so your existing stream add-ons, watch history and library all work exactly as before.

I see the same movies twice on my home screen.

Marquee's Trending rows follow the same popularity list as Cinemeta's built-in Popular rows. Open Lineup and press Hide Cinemeta's rows: they leave the home screen, and search keeps working.

Marquee's rows are at the bottom of my TV's home screen.

Stremio lists rows in the order add-ons were installed. Lineup → Marquee to the top fixes it on every device at once (only Continue Watching stays above).

Generated art or real posters?

Your choice: every theme comes in both. Real-poster versions keep the theme's curated collection, mood row, widescreen spotlight and row styling, but show the official artwork. Pick with the switch in the Install panel.

Can I install more than one theme?

Yes. Each theme is a separate add-on with its own rows, so you can mix them, say Hallowed in October next to Aurora all year. Use Lineup to put them in order.

How do I uninstall it?

In Stremio on any device: Add-ons → Installed → Marquee → Uninstall. It's removed from your account, so it disappears from your TV too.

Do I need to run a server?

No. The stock themes are static files on GitHub Pages, rebuilt daily so trending rows stay fresh. Your own Studio designs can be published the same way: Publish with GitHub adds a file to the repository and the daily build hosts it for free. A live server is optional, for changes that apply instantly.

Where does the data come from?

From Cinemeta, the same open catalog Stremio uses for its own home screen. The art is generated from each title's name, year, genres and rating, so no studio artwork is copied.

Will it slow down my TV?

Posters are small, cached JPEGs (about 30 KB each), comparable to Stremio's own.
